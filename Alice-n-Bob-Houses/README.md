# 🏡 Alice & Bob Houses — Real Estate Website

A responsive, client-side web application developed for **Alice & Bob Houses** as part of Assignment #4 for the Client-Side Programming course.

---

## 📌 Project Overview

The real estate agency **Alice & Bob Houses** requested a modernized online presence to showcase their properties for sale. This project aims to design, develop, test, and document an interactive, user-friendly client-side solution using core web technologies: **HTML5, CSS3, and JavaScript**.

> **Note:** Prior to implementation, a initial design mockup/proposal was created and approved by the client representative.

---

## ✨ Features & Requirements

### 1. 🏠 Property Listings
* Displays a list of all available properties currently for sale.
* Each property card presents key information:
  * Thumbnail image
  * Address
  * Size (in $\text{m}^2$)
  * Price
* Fully **responsive layout** designed to seamlessly adapt across mobile, tablet, and desktop screens.

### 2. 🔍 Detailed Property View
* Interactive selection: Users can click anywhere on a property card (thumbnail or text) to open a detailed view.
* Displays extended property information, including a detailed text description and an interactive location map integrated via **OpenStreetMap** / **Google Maps**.

### 3. 📅 Viewing Request Form
* Integrated booking form allowing potential buyers to request a property viewing.
* Includes input fields for:
  * Full Name
  * Contact Details (Email / Phone)
  * Preferred viewing date and time
* Form functionality facilitates sending viewing requests directly to Alice & Bob.

### 4. 📂 Data Handling
* Property data is statically stored and managed within client-side HTML structure as permitted by project specifications.

---

## 🛠️ Tech Stack

* **Structure:** HTML5
* **Styling:** CSS3 (Flexbox & Grid for responsive layout)
* **Interactivity:** Vanilla JavaScript (ES6+)
* **Mapping:** OpenStreetMap / Google Maps Embed API
* **Version Control:** Git & GitHub
