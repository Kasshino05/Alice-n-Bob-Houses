# Alice and Bob's Houses
Part of the final project Assignment #4 mean to be done in groups, for the client-side programming course.
    
### Dynamic Home-site
The real estate agency Alice & Bob Houses wishes to modernize its online presence by developing a new website that effectively showcases its properties for sale. The website must be user-friendly and interactive.

The aim of this case assignment is to design, develop, test, and document a client-side web solution that meets the requirements specified by Alice & Bob Houses. The solution must demonstrate proficiency in HTML, CSS, and JavaScript.

Before coding begins, a representative from Alice & Bob Houses must approve a mockup or proposal outlining your planned approach.


### Requirements

Property Display:

- The website must display a list of properties currently for sale by Alice & Bob Houses. Each property must be presented with a thumbnail image, address, size (in square meters), and price. 

- The list must be presented in a clear, responsive layout that adapts to various screen sizes (mobile, tablet, desktop).

Detailed View:

- Users must be able to click on any part of the property's thumbnail or text to view more detailed information about the property. 

- The detailed view page must present additional information, including a text description (placeholder text may be used) and a map showing the property's location. The map can be integrated using a service such as Google Maps or OpenStreetMap.

### Viewing request form
- A form must be developed allowing potential buyers to request a property viewing. 

- The form must include fields for entering a name, contact details, and a preferred time for the viewing. 

- The system must facilitate the easy sending of an email to Alice & Bob containing the relevant details regarding the requested viewing, or provide similar functionality.
  
### Data handling
- Alice & Bob Houses has agreed to have various houses hardcoded directly into the website's HTML.

### Delivering
- A fully functional website that meets all requirements in the specifications written by the teacher Rasmus.
